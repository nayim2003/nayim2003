Concept labs

Nine ideas every model depends on.

Each lab uses a fixed random seed, so what you see is reproducible. Change a control and the result updates instantly.

Central limit theorem

Draw 2,000 samples of size n from a skewed or two-peaked source, then plot each sample's mean. As n grows, the means pile up into a normal curve, even when the source is not normal.

Why it matters: confidence intervals and A/B tests lean on this. The spread of a mean shrinks like σ/√n, so quadrupling the data only halves the error.

Bias and variance

Twenty noisy points come from a sine wave. Raise the polynomial degree and compare error on the training points with error on 200 unseen points.

Training error always falls as the model grows. Test error falls, then rises. That turning point is why I validate on held-out data before trusting a score.

Threshold, precision and recall

A classifier scores 150 positive and 400 negative cases. Where you cut the score decides who gets flagged. Move the cut and read the confusion matrix.

Accuracy hides the trade-off when classes are imbalanced. Pick the threshold from the cost of a miss versus a false alarm, not from the default 0.5.

k-means clustering

Three hidden groups, no labels. Each step assigns every point to its nearest centre, then moves each centre to the mean of its points. Watch the total distance (inertia) fall.

k-means depends on where it starts. Try "New start" a few times: a bad start can split one group and merge two others.

Gradient descent

The curve is a loss with two valleys. Each step moves the weight against the slope, scaled by the learning rate. Too small is slow, too large overshoots, and the start decides which valley you land in.

Reaching a valley is not the same as reaching the best one. This is why I run training from several starts and track the loss curve.

Regularization: Ridge and Lasso

Only 25 training rows and 8 features, of which just 4 matter. Add a penalty λ and see how the coefficients shrink. Ridge shrinks them smoothly, Lasso sets weak ones to exactly zero.

Bars are estimates, outlined boxes are the true values. A little penalty usually lowers test error. Too much pushes everything to zero.

Neural network from scratch

A tiny network (2 inputs, one hidden layer, 1 output) learns to separate two interleaved moons. It is plain JavaScript with hand-written backpropagation. The coloured background is what the network currently believes.

With 1 hidden unit the boundary stays a straight line and cannot separate the moons. More units let it bend. That is what depth and width buy you.

Principal component analysis

These points are correlated. Rotate the axis and see how much of the total variance a single line captures. PCA finds the angle that keeps the most.

Reducing 2 columns to 1 loses the variance perpendicular to the axis. In real data I check the explained-variance curve before deciding how many components to keep.

Bayesian updating

A coin has a hidden bias towards heads. Pick a prior belief, flip the coin, and watch the belief move. More data pulls every prior to the same place.

The grey curve is the prior, the coloured curve is the posterior. The 95% credible interval narrows as flips accumulate. Compare it with a frequentist confidence interval in the Statistics page.

Glossary

Bias and variance
Bias is error from a model being too simple. Variance is error from a model reacting to noise. Good models balance them.
Class imbalance
One class is much rarer than the other, as in fraud. Accuracy becomes misleading, so use precision, recall, or PR-AUC.
Confidence interval
A range built so that, over many repeats, a stated share of such ranges would contain the true value.
Cross-validation
Splitting data into folds and rotating which fold is held out, to estimate performance on unseen data.
Data leakage
Information from outside the training set, often the future, sneaks into features and inflates the score.
Feature engineering
Creating inputs such as ratios, counts, or time windows that make the signal easier for a model to use.
p-value
How surprising the data would be if the null hypothesis were true. It is not the probability that the null is true.
Precision and recall
Precision is the share of flagged cases that are correct. Recall is the share of real cases that get flagged.
Regularization
A penalty on model size, such as Ridge (L2) or Lasso (L1), that reduces overfitting.
ROC-AUC
The chance that a random positive scores higher than a random negative. 0.5 is chance, 1.0 is perfect ranking.
SHAP
A method that splits a single prediction into per-feature contributions, so a model can be explained to non-experts.
Standard error
The spread of an estimate across repeated samples. For a mean it is σ divided by √n.
